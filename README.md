## ✨ Features
- **Guest Registration**: Quick entry for guest full name and company/affiliation.
- **Raffle Qualification**: Easy 1-tap confirmation or removal of guest eligibility.
- **Raffle Draw Stage**: Centered massive typography designed for big screens with drum roll sound synthesis and fanfare celebration!
- **Digital Signatures**: Digital signature canvas for claiming raffle prizes.
- **CSV Export**: Browser-native 1-click export of complete attendee logs.
- **Real-Time Synchronization**: Instant synchronization across tabs, mobile devices, and cloud backend.
